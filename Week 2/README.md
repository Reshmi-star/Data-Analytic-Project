# Week 2 — Logistics Data Cleaning and Preprocessing

## Files
- `Week2_Logistics_Data_Cleaning_Preprocessing_Report.docx`: report for the Week 2 task.
- `week2_logistics_preprocessing.py`: runnable Python preprocessing example.
- `README.md`: project notes.

## Important data note
The script uses a small synthetic practice dataset with deliberately introduced data-quality issues. It is not real company data. Replace it with a documented public dataset before reporting real findings.

## Run the example
Install dependencies:
```bash
python -m pip install pandas scikit-learn
```
Run:
```bash
python week2_logistics_preprocessing.py
```
The script prints checks and creates `cleaned_logistics_example.csv`.
